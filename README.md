# it-aptitude（IT適性診断）

ITの仕事への適性を診断する、単一ファイル Flask 製の Web ツールです。
質問・採点・解説文はすべて自作で、既存の適性検査の問題や文面は使用していません。

## 診断の内容

- 第1部：知的能力（全12問・4分野×3問）
  - 計数理解
  - 直感的推理・法則性理解
  - プログラミング言語適応能力
  - システム設計・デバッグ能力
- 第2部：パーソナリティ（全27問・9項目×3問、5段階で回答）
  - ヴァイタリティ／人あたり／チームワーク／創造的思考力／問題解決力／状況適応力／プレッシャーへの耐力／オーガナイズ能力／統率力

## 結果表示

- 総合判定（S〜Dランク）と総合スコア
- IT職種別の適職度（PG プログラマー／CE カスタマーエンジニア／SE システムエンジニア／PM プロジェクトマネージャー）
- 知的能力の分野別スコアと、問題ごとの正解・自分の回答の照合
- パーソナリティ9項目のレーダーチャートと項目ごとの解説
- 強み上位2項目にもとづく「面接での想定質問」

## 使い方

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

本番では `gunicorn app:app` で起動します。

## 注意

- この診断は参考用のツールです。結果は絶対的な判定ではありません。
- 回答はサーバーに保存されません（採点はリクエストの中でのみ行います）。

## テスト

```bash
python -m pytest tests/ -q
```
